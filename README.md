# Customer Support Dashboard

A responsive customer support dashboard built as part of a Frontend Developer Technical Task.

## Features

- Dashboard with ticket statistics
- View all support tickets
- Search tickets by ID, customer, or subject
- Filter by status and priority
- Change ticket status
- View detailed ticket information and conversations
- Loading, error, and empty states
- Responsive design for desktop and mobile

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Zustand – state management
- React Router – page navigation
- Lucide React – icons
- Mock API/data for tickets

## Getting Started

```bash
npm install
npm run dev
